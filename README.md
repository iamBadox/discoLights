# 🪩 Disco Lights

Turn your iPhone into a disco lamp! Fullscreen flashing colors synced to BPM or your music beat.

## Features

- **3 Modes**
  - **Ordered** — colors cycle in sequence at your chosen BPM
  - **Random / Chaos** — colors flash randomly at your chosen BPM
  - **Beat Reactive** 🎤 — mic detects ambient sound and flashes on the beat

- **5 Color Palettes** — Disco, Neon, Fire, Ocean, or fully Custom
- **BPM Slider** — 30 to 300 BPM
- **Beat sensitivity slider** — tune how eagerly Beat Reactive responds
- **Fullscreen mode** — max brightness, screen always on, hidden UI chrome
- **Safety warning** — shown once before first use (flashing lights epilepsy notice)

## Getting Started (iOS)

### Requirements

- Xcode 15+
- iOS 17+ deployment target
- [xcodegen](https://github.com/yonaskolb/XcodeGen) (to regenerate the `.xcodeproj` if needed)

### Build & Run

1. Open `iOS/DiscoLights.xcodeproj` in Xcode
2. Select your iPhone as the target device
3. Set your Development Team in project settings (required for device builds)
4. Hit ▶ Run

### Regenerate Xcode project

```bash
cd iOS
xcodegen generate
```

## Notes

- **Beat Reactive mode** listens to ambient sound via the microphone — it works best when music is playing aloud in the room. It cannot directly access audio from other apps.
- Brightness is restored to its original level when you exit disco mode.
- Double-tap the screen (or tap the stop button) to exit disco mode.
